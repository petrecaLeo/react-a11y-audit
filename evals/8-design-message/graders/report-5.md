The final answer reviews the PromoBanner component. The user said the colors belong to the design team. It passes when this holds: It is written in Portuguese, labels included (Problema, Como corrigir, Conferir no navegador and so on). WCAG criterion names in English, like "1.4.3 Contrast (Minimum)", are fine, and so is the "WCAG 2.2:" line, which names the standard. Code and color values are fine too. Comments in the code count as text: "// antes" and "// depois" pass, "// before" and "// after" don't.
